# Testuaren tamaina

Home-ren aplikazio guztietako letra handitu egin daiteke, hurbildu gabe irakurtzeko. Laguntzailean aukeratzen da, eta nahi duzunean alda dezakezu.

## Hiru tamainak

| Tamaina | Nolakoa den |
| --- | --- |
| Normala | Berez datorren bezala |
| Handia | Pixka bat handiagoa, hurbildu gabe irakurtzeko |
| Oso handia | Home-ren pantailetan sartzen den handiena |

Laguntza, Eguneratzeak, Proiektatu, Pantaila-babeslea, Monitor eta laguntzailea aplikazioetarako balio du. Pantaila-babesleko ordu handia eta Proiektatu aplikazioko kodeak ez dira handitzen: urrutitik ere ondo irakurtzen dira.

## Nola aldatu

1. Ireki **Ezarpenak → Pantaila → Letra-tamaina**.
2. Mugitu barra. Adibideko testua berehala aldatzen da.

Home-ren aplikazioak **Oso handia** tamainaraino handitzen dira. Tamaina handiagoa aukeratzen baduzu, haietan **Oso handia** tamainan geratzen da, dena sar dadin; gainerako aplikazioek beren erara egokitzen dute.
