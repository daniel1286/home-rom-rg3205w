# Kendu edo berriro jarri aplikazioak

Pantaila zurea da: erabiltzen ez duzuna, kendu. Home-ren aukerako aplikazioak eta laguntzailean aukeratu zenituenak beste edozein aplikazio bezala desinstalatzen dira; Proiektatu, berriz, Eguneratzeak aplikaziotik kentzen da.

## Zer ken daitekeen

| Aplikazioa | Kentzen baduzu |
| --- | --- |
| Laguntza | Ez duzu eskuliburu hau izango pantailan, ezta handik arazoak kontatzeko aukera ere. Gidak webean jarraitzen du |
| Monitor | Ez duzu pantaila barrutik ikusiko |
| Web panela | Ez duzu pantaila nabigatzailetik erabiliko, eta parekatutako nabigatzaileak ahaztu egiten dira |
| Proiektatu | Pantaila ez da gehiago agertzen beste gailuetan, eta bere ezarpenak eta parekatutako gailuak galdu egiten dira |
| Ahotsa | Ahotsez idazteko aukera, ahots-laguntzailea eta bere aktibatzeko hitza galtzen dituzu |
| Ahots hitz egina | Ahots-laguntzaileak pantailan bakarrik erantzuten du |
| Fully Kiosk, Snapcast, droidVNC-NG | Panelak, etxeko bozgorailuak edo ordenagailutiko kontrolak funtzionatzeari uzten diote |
| Aurora Store, F-Droid | Ezin duzu haiekin aplikaziorik instalatu, baina instalatutakoak geratu egiten dira |

Sistemaren aplikazioak (Eguneratzeak eta Pantaila-babeslea) ezin dira kendu.

## Aplikazio bat kendu

1. Ireki **Ezarpenak → Aplikazioak** eta ukitu **Ikusi aplikazio guztiak**.
2. Ukitu aplikazioa.
3. Sakatu **Desinstalatu** eta onartu.

Bere ikonoa sakatuta eduki eta **Desinstalatu** aukerara arrastatu ere egin dezakezu.

Proiektatu aplikazioak ez du **Desinstalatu** aukerarik: ireki **Eguneratzeak**, ukitu **Home aplikazioak** eta, **Proiektatu** lerroan, ukitu **Kendu** eta berretsi.

> [!IMPORTANT]
> Home-ren aplikazio bat kentzen baduzu (Laguntza, Monitor, Web panela, Ahotsa edo Proiektatu), eguneratzeek ez dute berez berriro jartzen: zuk jartzen baduzu bakarrik itzultzen da.

## Aplikazio bat berriro jarri

Home-ren aplikazioak (Laguntza, Monitor, Web panela, Ahotsa eta Proiektatu) Eguneratzeak aplikaziotik jartzen dira, baita pantaila konfiguratzean markatu ez zenituenak ere:

1. Ireki **Eguneratzeak** eta ukitu **Home aplikazioak**, behean.
2. **Aukerakoak** atalean jarrita ez daudenak agertzen dira: markatu ez zenituenek «Aukerakoa: ez dago jarrita» diote, eta kendu zenituenek «Kendu egin zenuen: zuk jartzen baduzu bakarrik itzultzen da».
3. Ukitu **Jarri** edo **Jarri berriro**.

Home-k dakarren bertsioa instalatzen da, edo berriago bat, baldin badago. Proiektatu berehala itzultzen da, ezer deskargatu gabe, eta hutsetik hasten da. Bat ere ez da berez jartzen.

Aurora Store, F-Droid, Fully Kiosk, Snapcast eta droidVNC-NG Aurora Store edo F-Droid bidez instalatzen dira berriro, edo beren webgunetik.

Laguntza ez duzun bitartean, eskuliburua webean irakur dezakezu, [Home-ren gidan](https://github.com/daniel1286/home-rom-rg3205w/blob/main/guias/eu/README.md).
