# Lehen urratsak

Lehen aldiz pizten denean, Home-k laguntzaile bat irekitzen du, eta minutu gutxitan uzten du pantaila prest. Hemen duzu urrats bakoitzak zer eskatzen duen, zer komeni den aukeratzea eta gero non aldatzen den.

## Hasi aurretik

- Pantailak entxufatuta egon behar du. Ez du bateriarik: deskonektatzen baduzu, itzali egiten da.
- Izan eskura zure Wi-Fi sarearen pasahitza.
- Home Assistant panel gisa edo etxeko bozgorailu gisa erabiliko baduzu, utzi zure zerbitzaria piztuta: laguntzaileak sarean bilatzen du.

Urrats guztietan, **Atzera** duzu behean ezkerrean, eta **Hurrengoa** behean eskuinean. Ia ezer ez da aplikatzen amaiera arte; beraz, lasai joan zaitezke aurrera eta atzera.

## Hizkuntza, eskualdea eta testua

**Kaixo.** Aukeratu hizkuntza: laguntzailea berehala aldatzen da, eta pantaila hizkuntza horretan geratzen da. Gero, sakatu **Hasi**.

**Eskualdea eta ordua.** Ordu-eremua (Penintsula eta Balear Uharteak, Kanariak, Ceuta eta Melilla edo Portugal), ordua Internetetik hartzen den eta 24 orduko formatuan nahi duzun.

**Testuaren tamaina.** Normala, Handia edo Oso handia. Bat ukitzean, laguntzaile osoa aldatzen da, nola geratzen den ikus dezazun. Home-ren aplikazio guztietarako balio du, pantaila-babeslea barne.

## Wi-Fia eta izena

**Wi-Fi.** Aukeratu zure sarea, idatzi pasahitza eta sakatu **Konektatu**. Ez bada agertzen, sakatu **Bilatu berriro**. Urrats hau salta dezakezu, baina konexiorik gabe ezin da Home Assistant panela instalatu, ezta ordua automatikoki jarri ere.

**Izena.** Nola deituko den pantaila zure sarean, Bluetooth bidez eta proiektatzean. Etxean bat baino gehiago badituzu, jarri gelaren izena: Egongela, Sukaldea, Sarrera…

## Zer instalatu nahi duzu

Markatu erabiliko duzuna. Markatzen ez duzuna ez da instalatzen eta ez du lekurik hartzen.

| Aukera | Zertarako |
| --- | --- |
| Home Assistant panela | Zure panela pantaila osoan, piztean bere kasa irekitzen dena. Fully Kioskek erakusten du |
| Etxeko bozgorailua | Pantailak etxeko gainerako bozgorailuekin batera jotzea, zure musika-zerbitzariarekin |
| Pantaila ordenagailutik erabili | Pantaila beste ordenagailu batetik ikusi eta ukitzea |
| F-Droid | Aplikazio libre eta doakoen denda |
| Aurora Store | Google Playko aplikazioak Google konturik gabe |
| Laguntza | Gida hau eta, zerbaitek huts egiten badu, kontatu eta erantzuna ikustea |
| Monitor | Pantaila barrutik ikustea: prozesadorea, memoria, tenperaturak eta sarea |

Laguntza, F-Droid eta Aurora Store markatuta datoz; Monitor, ez. Laguntza eta Monitor gero beste edozein aplikazio bezala desinstalatzen dira.

Panela edo bozgorailua markatzen badituzu, bi urrats gehiago agertzen dira:

- **Home Assistant.** Laguntzaileak zure sarean bilatzen du. Aurkitzen ez badu, idatzi helbidea, adibidez `homeassistant.local:8123`. Zure Home Assistantek ziurtagiri propioa erabiltzen badu, gehitu **Aukera aurreratuak** atalean.
- **Etxeko bozgorailua.** Aukeratu zure musika-zerbitzaria zerrendan edo idatzi haren helbidea.

## Proiektatu eta pantaila atsedenean

**Proiektatu.** Utzi pantaila honi iPhone-aren, Mac-aren, Windows ordenagailuaren edo Android mugikorraren irudia eta soinua jasotzen. Aukeratu nork bidal dezakeen:

- **Kodearekin lehen aldian** (horrela dator): lehen aldian, Apple gailuek pantailan agertzen den lau zifrako kode bat idazten dute, eta besteek baimena eskatzen dute pantailan bertan.
- **Etxeko edonork**: zure sarera konektatutako edozein gailuk bidaltzen du, galdetu gabe.
- **Pasahitzarekin**: Apple gailuek zuk aukeratzen duzun pasahitz bat erabiltzen dute; besteek baimena eskatzen dute lehen aldian.

Aktibatuta dator. Erabiliko ez baduzu, desaktibatu **Jaso pantaila honetan** eta Proiektatu kendu egiten da; nahi duzunean jar dezakezu berriro **Eguneratzeak → Home aplikazioak** aukeran, **Aukerakoak** atalean.

**Pantaila atsedenean.** Zer gertatzen den inork ukitzen ez duenean:

- **Pantaila-babeslea agertzen da**: ordua, eguraldia eta zure atzealdeak. Aukeratu zenbat denboraren buruan agertzen den eta zure hiria; hortik ateratzen dira eguraldia, euria eta hegazkinak.
- **Dagoena geratzen da** (horrela dator): aurrean geratzen da panela edo irekita daukazun aplikazioa.

Iratzargailuak bi kasuetan jotzen du.

**Pantaila.** Distira eta, pantaila-babeslea erabiltzen ez baduzu, zenbat denboraren buruan itzaltzen den. Panel edo erloju gisa erabiltzen baduzu, aukeratu **Inoiz ez**.

**Nabigazioa.** Nola mugitzen zaren pantailan: **Keinuak** erabiliz (horrela dator) edo **Botoiak** erabiliz, beti ikusgai behean. [Nola mugitu Home-n](moverte-por-home.md) gidan dago azalduta.

## Pribatutasuna eta aukera aurreratuak

**Pribatutasuna.** Mikrofonoa eta kamera erabil daitezkeen ala ez. Kamera desaktibatuta dator.

**Lagundu Home hobetzen.** Nahi baduzu, pantailak egunean behin kontatzen du nola dagoen konfiguratuta eta eguneratzeak ondo doazen. Itzalita dator: aktibatzen baduzu bakarrik bidaltzen da. Urratsak esaten du zer bidaltzen den eta zer ez den inoiz bidaltzen.

**Aukera aurreratuak.** IP finkoa, MAC helbidea, ziurtagiri propioak, ADB arazketa eta root-a. Behar ez badituzu, sakatu **Jarraitu**. Bakoitzak bere azalpena du [Aurreratua](README.md#aurreratua) atalean.

## Laburpena

Berrikusi dena. Ukitu lerro bat aldatzeko eta, dena ondo dagoenean, sakatu **Aplikatu**.

Pantailak egiten ari dena esaten du. Bitartean, ez itzali eta ez deskonektatu. Zerbait ez bada ondo ateratzen, goian erakusten du eta laburpenera itzultzen uzten dizu; gainerakoa jarrita geratzen da. Amaitzean, sakatu **Hasi erabiltzen**. Ez da berrabiarazi behar.

## Gero non aldatzen den

| Zer | Non |
| --- | --- |
| Hizkuntza | Ezarpenak → Sistema → Hizkuntzak |
| Testuaren tamaina | Ezarpenak → Pantaila → Letra-tamaina |
| Wi-Fia | Ezarpenak → Sareak eta Internet |
| Izena | Ezarpenak → Gailuari buruz → Gailuaren izena |
| Proiektatu | Proiektatu aplikazioa |
| Pantaila-babeslea | Pantaila-babeslea aplikazioa → Erabiltzeari uztean |
| Distira eta itzaltzea | Ezarpenak → Pantaila |
| Keinuak edo botoiak | Ezarpenak → Sistema → Keinuak → Sistemaren nabigazioa |
| Lagundu Home hobetzen | Eguneratzeak aplikazioa → Ezarpenak |
| ADB arazketa | Ezarpenak → Sistema → Garatzaileentzako aukerak |
