# Se unha actualización non se instala

Se algo falla, Actualizacións di «Non se actualizou», en que versión segues e por que. As túas apps, axustes e datos non se tocan. Aquí tes que facer en cada caso.

## Que quere dicir cada aviso

| Aviso | Que facer |
| --- | --- |
| Cortouse a conexión a internet | Comproba a wifi e toca **Tentar de novo**. O descargado aprovéitase |
| Non hai espazo abondo no aparello | Fai falta o dobre do que ocupa a versión. Libera espazo e téntao de novo |
| Non se puido ler o ficheiro | Comproba que o ficheiro segue na pantalla e escólleo outra vez |
| O paquete non coincide co publicado | Danouse polo camiño. Téntao de novo: descárgase outra vez |
| O paquete non está asinado por Home | Por seguridade, só se instala o que é de Home. Descárgao desde a app, non doutro sitio |
| O paquete é para outro aparello | Instalalo podería deixar a pantalla sen arrincar. Usa o de Home para o RG3205W |
| O paquete non é máis novo ca o que tes | Volver a unha versión anterior podería estragar os teus datos, así que non se instala |
| O paquete é unha actualización parcial para outra versión | Só vale sobre a versión da que parte. Usa o paquete completo |
| Non se puido deixar listo o paquete | Segue descargado: téntao de novo sen descargalo outra vez |
| O recovery non puido instalar o paquete | Segue descargado: téntao de novo. Se se repite, cóntao |

## Se queda en negro ao reiniciar

Co cable USB do ordenador posto, a pantalla non remata de arrincar. Quita o cable, desenchúfaa da corrente e volve enchufala.

## Se segue sen instalarse

[Cóntao](contar-un-problema.md) desde Axuda, escollendo **Actualizacións**, co aviso que aparece e achegando o rexistro do sistema.
