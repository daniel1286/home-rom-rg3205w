# Projetar a partir do Android

Para ver no ecrã o que tens no telemóvel ou no tablet Android. Muitos telemóveis trazem um botão próprio para projetar; para os que não trazem, existe a app «Enviar para Home». Em ambos os casos, o telemóvel tem de estar no mesmo Wi-Fi que o ecrã.

## Antes de começar

No ecrã, abre a app **Projetar** e confirma que está ativado e que em **De onde** está ligado **Windows e Android**. **Só som** tem de estar desligado.

## Com o botão do telemóvel

1. Desliza para baixo a partir do topo para abrir as definições rápidas. Podes ter de deslizar duas vezes.
2. Toca no botão de projetar ou de partilhar o ecrã. Cada marca chama-lhe à sua maneira.
3. Escolhe o teu ecrã, por exemplo **Sala**.
4. Se o telemóvel pedir um PIN, escreve o que aparece no ecrã.
5. Da primeira vez, o ecrã pergunta «Deixar … enviar para este ecrã?». Toca em **Permitir**.

Para parar, volta a tocar no mesmo botão no telemóvel.

## Com a app «Enviar para Home»

Para os telemóveis com Android 10 ou posterior que não trazem botão para projetar.

1. Instala a «Enviar para Home» no telemóvel. Transfere-se a partir das [versões do Home](https://github.com/daniel1286/home-rom-rg3205w/releases/latest).
2. Abre-a. Procura sozinha os ecrãs Home do teu Wi-Fi: escolhe o teu.
3. Se também quiseres ouvir o som das apps, ativa **Enviar também o som**. Para isso, o Android pede a autorização do microfone, mas o microfone não é usado.
4. Aceita quando o Android perguntar se deixas gravar o ecrã.
5. Da primeira vez, aceita no ecrã que o telemóvel envie.

Para parar, toca em **Parar de enviar** na notificação do telemóvel.

## Se o ecrã não aparecer

- Confirma que o telemóvel e o ecrã estão na mesma rede. As redes de convidados do router costumam impedir que os aparelhos se vejam uns aos outros.
- Revê o ponto [Antes de começar](#antes-de-começar).
- Se com o botão do telemóvel o ecrã não aparecer, experimenta a «Enviar para Home».

> [!WARNING]
> Os filmes e séries pagos ficam pretos: a proteção contra cópia não deixa enviá-los para outro ecrã.
