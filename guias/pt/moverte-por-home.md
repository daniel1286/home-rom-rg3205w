# Navegar no Home

O Home usa-se com gestos, como os telemóveis atuais: em baixo não há botões, só uma pequena barra. Se preferires os três botões de sempre, muda-se num instante.

## Com gestos

| Para | Faz isto |
| --- | --- |
| Voltar atrás | Desliza da margem esquerda ou direita para o centro |
| Ir para o ecrã principal | Desliza para cima a partir da barra em baixo |
| Ver as apps recentes | Desliza para cima a partir da barra até meio do ecrã e mantém o dedo um momento |
| Voltar à app anterior | Desliza para a esquerda ou para a direita sobre a barra |

Nas apps em ecrã inteiro, a barra esconde-se. Desliza a partir da margem de baixo para que apareça e repete o gesto.

## Com botões

Em baixo aparecem três botões, sempre à vista:

| Botão | O que faz |
| --- | --- |
| Voltar | Volta ao ecrã anterior |
| Início | Vai para o ecrã principal |
| Recentes | Mostra as apps abertas para passar de uma para outra ou fechá-las |

## Mudar entre gestos e botões

1. Abre as **Definições**.
2. Entra em **Sistema → Gestos → Navegação no sistema**. Se não encontrares, toca na lupa das Definições e procura «navegação».
3. Escolhe **Navegação com 3 botões** ou **Navegação por gestos**.

Muda logo, sem reiniciar.

## Notificações e definições rápidas

- Desliza para baixo a partir do topo do ecrã para ver as notificações.
- Volta a deslizar para baixo para abrir as definições rápidas: Wi-Fi, Bluetooth, brilho e mais.
- Para as fechar, desliza para cima ou volta atrás.
