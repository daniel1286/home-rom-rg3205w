# Se uma atualização não for instalada

Se algo falhar, a app Atualizações diz «Não foi atualizado», em que versão continua e porquê. As tuas apps, definições e dados não são tocados. Aqui fica o que fazer em cada caso.

## O que significa cada aviso

| Aviso | O que fazer |
| --- | --- |
| A ligação à internet foi cortada | Verifica o Wi-Fi e toca em **Tentar novamente**. O que foi transferido é aproveitado |
| Não há espaço suficiente no aparelho | É preciso o dobro do que a versão ocupa. Liberta espaço e tenta de novo |
| Não foi possível ler o ficheiro | Confirma que o ficheiro continua no ecrã e escolhe-o outra vez |
| O pacote não coincide com o publicado | Danificou-se pelo caminho. Tenta de novo: volta a ser transferido |
| O pacote não está assinado pelo Home | Por segurança, só se instala o que é do Home. Transfere-o a partir da app, não de outro sítio |
| O pacote é para outro aparelho | Instalá-lo podia impedir o ecrã de arrancar. Usa o do Home para o RG3205W |
| O pacote não é mais recente do que o que tens | Voltar a uma versão anterior podia estragar os teus dados, por isso não é instalado |
| O pacote é uma atualização parcial para outra versão | Só serve sobre a versão de que parte. Usa o pacote completo |
| Não foi possível deixar o pacote pronto | Continua transferido: tenta de novo sem o transferir outra vez |
| O recovery não conseguiu instalar o pacote | Continua transferido: tenta de novo. Se voltar a acontecer, conta o problema |

## Se ficar preto ao reiniciar

Com o cabo USB do computador ligado, o ecrã não acaba de arrancar. Retira o cabo, desliga o ecrã da tomada e volta a ligá-lo.

## Se continuar sem instalar

[Conta o problema](contar-un-problema.md) a partir da Ajuda, escolhendo **Atualizações**, com o aviso que aparece e anexando o registo do sistema.
