# If an update won't install

If something fails, Updates says “Not updated”, which version you're still on and why. Your apps, settings and data aren't touched. Here's what to do in each case.

## What each message means

| Message | What to do |
| --- | --- |
| The internet connection was lost | Check the Wi-Fi and tap **Try again**. What was already downloaded is kept |
| There isn't enough space on the device | It needs twice the size of the version. Free up some space and try again |
| The file couldn't be read | Check that the file is still on the screen and choose it again |
| The package doesn't match the published one | It got damaged on the way. Try again: it's downloaded again |
| The package isn't signed by Home | For safety, only Home packages are installed. Download it from the app, not from anywhere else |
| The package is for another device | Installing it could leave the screen unable to start. Use the Home package for the RG3205W |
| The package isn't newer than what you have | Going back to an older version could damage your data, so it isn't installed |
| The package is a partial update for another version | It only works on the version it starts from. Use the full package |
| The package couldn't be made ready | It's still downloaded: try again without downloading it again |
| The recovery couldn't install the package | It's still downloaded: try again. If it keeps happening, report it |

## If it stays black when restarting

With the computer's USB cable connected, the screen doesn't finish starting up. Remove the cable, unplug the screen from the mains and plug it back in.

## If it still won't install

[Report it](contar-un-problema.md) from Help, choosing **Updates**, with the message it shows, and attach the system log.
