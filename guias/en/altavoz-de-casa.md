# House speaker

With a music server at home, the screen plays in sync with the rest of your speakers. It uses the Snapcast app, which gets installed if you tick **House speaker** in the setup wizard.

## What you need

- A Snapcast server on your network. Many home music systems include one or can use one.
- The screen and the server on the same network.

## How it's set up

In the setup wizard you choose the server from the list, or type its address, and the screen connects with its own name. From then on:

- Snapcast starts by itself every time the screen is switched on.
- What plays and the volume are controlled from the server or from the app you use to play music.

## Changing server

Open the **Snapcast** app and choose the new server in its settings.

## If there's no sound

- Open **Snapcast** and check that it's connected to your server.
- If the server can't see the screen, give it a name from the server itself.
- Make sure the screen's volume isn't all the way down, with **Vol +**.

To play from an iPhone or a Mac without a server, see [Sound only](solo-sonido.md).
