# Monitor

Monitor shows you live how the screen is doing inside: the processor, memory, temperatures, network and versions. It's optional: you tick it in the setup wizard and you can uninstall it.

## What it shows

| Section | What's there |
| --- | --- |
| Overview | Whether something is wrong or everything is fine, and a tile for each thing. Each tile takes you to its section |
| Performance | Processor usage over the last minute, each core, graphics and temperatures |
| Memory | Memory in use, the apps using the most, and storage space |
| Network | Wi-Fi, signal, speed, addresses and traffic |
| Device | The parts: processor, graphics, display, sound and connectivity |
| System | The Home and Android versions, uptime, and Home's apps and services |

It only reads while you have it in front of you: when it's closed, it uses nothing.

## Create a report

In **Overview**, tap **Create report**. It copies a summary of how the screen is doing so you can paste it when you [report a problem](contar-un-problema.md). It doesn't include your network name, addresses or the MAC.

## Your privacy

- Monitor doesn't use the Internet: nothing it shows leaves the screen.
- The MAC address stays hidden until you tap **Show**.
- It doesn't store anything.

## If you don't have it

On a new installation, you tick it in **What to install**. If you updated from an earlier version, it's offered in “What's new” for version 2.1. If you didn't tick it, or you removed it, add it from **Updates → Home apps → Optional**.
