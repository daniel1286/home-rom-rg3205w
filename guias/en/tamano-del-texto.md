# Text size

You can make the text bigger in every Home app so you can read it without getting closer. You choose it in the setup wizard and can change it whenever you like.

## The three sizes

| Size | What it's like |
| --- | --- |
| Normal | The size it comes with |
| Large | A little bigger, to read without getting closer |
| Very large | As big as the Home screens allow |

It applies to Help, Updates, Cast, Screensaver, Monitor and the setup wizard. The big clock on the screensaver and the Cast codes don't grow: they're already easy to read from a distance.

## Changing it

1. Open **Settings → Display → Font size**.
2. Move the slider. The sample text changes right away.

Home's apps grow up to **Very large**. If you pick a bigger size, they stay at **Very large** so everything fits; other apps follow it in their own way.
