# Automatic check and “Help improve Home”

In **Updates → Settings** you choose how often it checks for new versions and whether the screen helps improve Home by reporting how it's doing. Both are up to you.

## Automatic check

It only lets you know: downloading and installing is always your decision.

| Option | When it checks |
| --- | --- |
| Every 6 hours | Four times a day |
| Every day | Once a day. This is the default |
| Every week | Once a week |
| Never, manual only | Only when you tap **Check now** |

## Help improve Home

If you turn it on, the screen reports once a day how it's set up and whether updates go well. It helps decide what to fix first. It's off by default: nothing is sent unless you turn it on, here or in the setup wizard.

What is sent:

- The Home version and its build number.
- The mode (panel, speaker or tablet), the language and whether you use gestures or buttons.
- Which features you use: the screensaver, Cast and from what, Bluetooth and root.
- Whether each update installs correctly and, if not, why.

What is never sent: the screen's name, the Wi-Fi network, the location, the Home Assistant address, your apps or anything you type. The IP address isn't stored.

## See it and delete it

- **See what is sent**: today's exact message, just as it leaves the screen.
- **Get a new identifier**: everything sent so far is deleted and it starts from scratch.
- If you turn it off, what was sent is deleted too.

It uses a random identifier that doesn't say who you are or which screen it is.
