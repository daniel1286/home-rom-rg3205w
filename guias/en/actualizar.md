# Update Home

When a new version of Home comes out, the Updates app lets you know. You decide when to download and install it, and your apps, settings and data stay as they are.

## When there's a new version

A notification shows up: “Home … available”. Nothing is installed unless you ask.

1. Tap the notification or open the **Updates** app. It's also in **Settings → System → System updates**.
2. Read what's new in the version and tap **Download**. You can see how much is done and how much is left.
3. When it finishes, the app checks that the package arrived complete, that Home signed it, that it's for this device and that it's newer than yours.
4. Tap **Install and restart**.

The screen restarts into the recovery, which installs the version and shows its progress. It takes a few minutes. Then it goes back to Home by itself and the “Home has been updated” notification shows up.

> [!WARNING]
> Don't unplug it while it installs. And remove the computer's USB cable if it's connected: with it, the screen doesn't finish starting up.

## What's new

If the new version brings something to set up, “What's new” opens at startup with its steps. You can do it right then or tap **Later**: it will show up again at the next startup.

Right after updating, Updates also shows **See what's new**, so you can look at it whenever you like.

## Check by hand

In **Updates**, tap **Check now**. If you're up to date, it says “You have the latest version” and when it last checked.

How often it checks by itself is chosen in [Automatic check and “Help improve Home”](busqueda-y-ayudar.md).

## What it downloads

The app picks the smallest package that works for your screen by itself:

- If you have the version it starts from, it only downloads what changes: a few tens of MB.
- If not, it downloads the whole system: more than 1 GB.

If the connection drops, it picks up where it left off when you try again.

## Install from a file

If you have the package on the screen, in **Updates** tap **Install from a file** and choose it. It's checked just like a downloaded one: it only installs if Home signed it and it's for this device.

If something goes wrong, see [If an update won't install](si-no-se-instala.md).
