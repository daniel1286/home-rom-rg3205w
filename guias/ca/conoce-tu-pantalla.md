# Coneix la teva pantalla

Home converteix l'Askey RG3205W en una pantalla per a casa amb Android 15: un tauler de Home Assistant, un altaveu, un rellotge o una tauleta de 8 polzades. Aquí tens el més bàsic de l'aparell i de Home.

## Els botons

- **Engegada**: el botó blanc de darrere, al costat de la presa de corrent.
- **Vol +** i **Vol −**: a dalt.

| Què vols fer | Fes això |
| --- | --- |
| Apagar o encendre la pantalla | Prem **Engegada** un cop |
| Apagar o reiniciar l'aparell | Mantén premut **Engegada** i tria al menú |
| Apujar o abaixar el volum | Prem **Vol +** o **Vol −** |

## Sempre endollada

La pantalla no té bateria: funciona endollada al corrent i, si la desendolles, s'apaga. Quan la tornes a endollar, arrenca sola.

Tampoc no té pila per al rellotge, així que pren l'hora d'Internet. Per això convé tenir-la connectada a la Wi-Fi.

Està pensada per estar sempre encesa: de sèrie, la pantalla no s'apaga encara que ningú no la toqui. Si vols que s'apagui o que surti l'estalvi de pantalla, ho pots triar a l'assistent o després, a [L'estalvi de pantalla](salvapantallas.md).

> [!WARNING]
> Amb el cable USB de l'ordinador connectat, la pantalla no acaba d'arrencar. Treu-lo abans de reiniciar-la.

## El que porta dins

| Peça | Què té |
| --- | --- |
| Pantalla | 8 polzades, 1280 × 800, tàctil |
| So | Dos altaveus i quatre micròfons |
| Connexions | Wi-Fi de 2,4 i 5 GHz, i Bluetooth |
| Càmera | Una, que ve desactivada |

## Les apps de Home

| App | Per a què |
| --- | --- |
| Ajuda | Aquest manual i explicar un problema |
| Actualitzacions | Cercar i instal·lar les versions noves de Home |
| Projectar | Rebre la imatge i el so d'altres aparells |
| Estalvi de pantalla | L'hora, el temps i el despertador quan no la fas servir |
| Monitor | Veure la pantalla per dins, si la vas instal·lar |

Ajuda i Monitor es poden desinstal·lar com qualsevol app. A més, hi ha les que vas triar a l'assistent: el tauler de Home Assistant, l'altaveu de casa, F-Droid, Aurora Store… A la pantalla d'inici, llisca cap amunt per veure-les totes.
