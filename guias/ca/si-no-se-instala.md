# Si una actualització no s'instal·la

Si alguna cosa falla, Actualitzacions diu «No s'ha actualitzat», en quina versió continues i per què. Les teves apps, ajustos i dades no es toquen. Aquí tens què has de fer en cada cas.

## Què vol dir cada avís

| Avís | Què has de fer |
| --- | --- |
| S'ha tallat la connexió a internet | Comprova la Wi-Fi i toca **Torna-ho a provar**. El que s'ha baixat s'aprofita |
| No hi ha prou espai a l'aparell | Cal el doble del que ocupa la versió. Allibera espai i torna-ho a provar |
| No s'ha pogut llegir el fitxer | Comprova que el fitxer encara és a la pantalla i torna a triar-lo |
| El paquet no coincideix amb el publicat | S'ha malmès pel camí. Torna-ho a provar: es baixa de nou |
| El paquet no està signat per Home | Per seguretat, només s'instal·la el que és de Home. Baixa'l des de l'app, no des d'un altre lloc |
| El paquet és per a un altre aparell | Instal·lar-lo podria impedir que la pantalla arrenqui. Fes servir el de Home per al RG3205W |
| El paquet no és més nou que el que tens | Tornar a una versió anterior podria malmetre les teves dades, així que no s'instal·la |
| El paquet és una actualització parcial per a una altra versió | Només serveix sobre la versió de la qual parteix. Fes servir el paquet complet |
| No s'ha pogut deixar a punt el paquet | Continua baixat: torna-ho a provar sense haver-lo de baixar un altre cop |
| El recovery no ha pogut instal·lar el paquet | Continua baixat: torna-ho a provar. Si es repeteix, explica-ho |

## Si es queda en negre en reiniciar

Amb el cable USB de l'ordinador connectat, la pantalla no acaba d'arrencar. Treu el cable, desendolla-la del corrent i torna-la a endollar.
