# Conoce tu pantalla

Home convierte el Askey RG3205W en una pantalla para casa con Android 15: un panel de Home Assistant, un altavoz, un reloj o una tablet de 8 pulgadas. Aquí tienes lo básico del aparato y de Home.

## Los botones

- **Encendido**: el botón blanco de atrás, junto a la toma de corriente.
- **Vol +** y **Vol −**: arriba.

| Para | Haz esto |
| --- | --- |
| Apagar o encender la pantalla | Pulsa **Encendido** una vez |
| Apagar o reiniciar el aparato | Mantén pulsado **Encendido** y elige en el menú |
| Subir o bajar el volumen | Pulsa **Vol +** o **Vol −** |

## Siempre enchufada

La pantalla no tiene batería: funciona enchufada a la corriente y, si se desenchufa, se apaga. Al volver a enchufarla, arranca sola.

Tampoco tiene pila para el reloj, así que toma la hora de Internet. Por eso conviene tenerla conectada a la Wi-Fi.

Viene para estar siempre encendida: de serie, la pantalla no se apaga por no tocarla. Si quieres que se apague o que salga el salvapantallas, se elige en el asistente o después, en [El salvapantallas](salvapantallas.md).

> [!WARNING]
> Con el cable USB del ordenador puesto, la pantalla no termina de arrancar. Quítalo antes de reiniciarla.

## Lo que lleva dentro

| Pieza | Qué tiene |
| --- | --- |
| Pantalla | 8 pulgadas, 1280 × 800, táctil |
| Sonido | Dos altavoces y cuatro micrófonos |
| Conexiones | Wi-Fi de 2,4 y 5 GHz, y Bluetooth |
| Cámara | Una, que viene desactivada |

## Las apps de Home

| App | Para qué |
| --- | --- |
| Ayuda | Este manual y contar un problema |
| Actualizaciones | Buscar e instalar las versiones nuevas de Home |
| Proyectar | Recibir la imagen y el sonido de otros aparatos |
| Salvapantallas | La hora, el tiempo y el despertador cuando no la usas |
| Monitor | Ver la pantalla por dentro, si la instalaste |

Ayuda y Monitor se pueden desinstalar como cualquier app. Además están las que elegiste en el asistente: el panel de Home Assistant, el altavoz de casa, F-Droid, Aurora Store… En la pantalla de inicio, desliza hacia arriba para verlas todas.
