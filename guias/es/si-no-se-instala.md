# Si una actualización no se instala

Si algo falla, Actualizaciones dice «No se ha actualizado», en qué versión sigues y por qué. Tus apps, ajustes y datos no se tocan. Aquí tienes qué hacer en cada caso.

## Qué quiere decir cada aviso

| Aviso | Qué hacer |
| --- | --- |
| Se ha cortado la conexión a internet | Comprueba la Wi-Fi y pulsa **Volver a intentarlo**. Lo descargado se aprovecha |
| No hay sitio suficiente en el aparato | Hace falta el doble de lo que ocupa la versión. Libera espacio y vuelve a intentarlo |
| No se ha podido leer el archivo | Comprueba que el archivo sigue en la pantalla y elígelo otra vez |
| El paquete no coincide con el publicado | Se ha dañado por el camino. Vuelve a intentarlo: se baja de nuevo |
| El paquete no está firmado por Home | Por seguridad, solo se instala lo que es de Home. Bájalo de la app, no de otro sitio |
| El paquete es para otro aparato | Instalarlo podría dejar la pantalla sin arrancar. Usa el de Home para el RG3205W |
| El paquete no es más nuevo que lo que tienes | Volver a una versión anterior podría estropear tus datos, así que no se instala |
| El paquete es una actualización parcial para otra versión | Solo vale sobre la versión de la que parte. Usa el paquete completo |
| No se ha podido dejar listo el paquete | Sigue descargado: vuelve a intentarlo sin bajarlo otra vez |
| El recovery no ha podido instalar el paquete | Sigue descargado: vuelve a intentarlo. Si se repite, cuéntalo |

## Si se queda en negro al reiniciar

Con el cable USB del ordenador puesto, la pantalla no termina de arrancar. Quita el cable, desenchúfala de la corriente y vuelve a enchufarla.

## Si sigue sin instalarse

[Cuéntalo](contar-un-problema.md) desde Ayuda, de **Actualizaciones**, con el aviso que sale y adjuntando el registro del sistema.
