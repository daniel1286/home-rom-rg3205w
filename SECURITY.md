# Seguridad / Security

Si encuentras un fallo de seguridad en Home, no abras una incidencia pública. Avísame en privado desde la pestaña **Security → Report a vulnerability** de este repositorio. Te contestaré lo antes posible y, cuando esté arreglado, saldrá en las notas de la release.

Solo se mantiene la última versión publicada en [Releases](https://github.com/daniel1286/home-rom-rg3205w/releases/latest).

---

If you find a security issue in Home, please don't open a public issue. Report it privately from the **Security → Report a vulnerability** tab of this repository. I'll reply as soon as I can and, once it's fixed, it will be mentioned in the release notes.

Only the latest version in [Releases](https://github.com/daniel1286/home-rom-rg3205w/releases/latest) is maintained.
